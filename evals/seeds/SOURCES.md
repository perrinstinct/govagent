# Seed specs

The seeds are lint-clean OpenAPI documents (zero violations against
`rulesets/governance.spectral.yaml`) from which the eval dataset is generated by mutation.

All of them were written by hand for this project. They describe fictional APIs and are
licensed under the repository's MIT license. No third-party or employer content is included.

| Seed | Format | Notes |
|---|---|---|
| `petstore.yaml` | OpenAPI 3.0, YAML, 2-space, comments | shared `$ref` responses and parameters |
| `bookshop.yaml` | OpenAPI 3.1, YAML, 4-space, unindented sequences | inline problem responses, a 5xx |
| `payments.json` | OpenAPI 3.0, JSON | OAuth2, shared responses |
| `iot-devices.yaml` | OpenAPI 3.0, YAML, flow style | server variables, inline responses |
| `hr-employees.yaml` | OpenAPI 3.1, YAML | nested object schema, OIDC |
| `events-tickets.yaml` | OpenAPI 3.0, YAML, comments | one shared response reused everywhere, a 5xx |
